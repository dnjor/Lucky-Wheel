# Lucky Wheel — Google Apps Script setup

1. Open the Google Sheet owned by the teacher.
2. Open **Extensions → Apps Script**.
3. Enable the **Drive API v3** advanced service.
4. Replace the default `Code.gs` contents with `Code.gs` from this folder.
5. Add HTML files named `Index`, `Stylesheet`, and `JavaScript` (prepared separately).
6. Select `setup` in the function dropdown and run it once.
7. Approve the requested Sheet and Drive permissions.
8. Deploy as a web app, executing as the teacher, with access set to **Only myself**.

No API key or paid Google Cloud project is required.
